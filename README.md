Entry for the [make.fun competition "The Best Meal You Ever Had"](https://make.fun/competitions/u-pangg7-the-best-meal-you-ever-had-a3ac0f85).

## What it does

`main.py` writes one sentence — 138 characters — about the best meal the entrant ever had, to `/output/entry.txt`. It is deterministic, uses no network, reads no input, and holds no secrets. Before writing, it self-checks the competition gate: the entry must be 1–200 characters and exactly one sentence, and the program exits non-zero instead of writing anything invalid.

## The sentence

> The rawon my aunt served after my grandfather's funeral, black broth and tender beef, was the first thing that made grief feel survivable.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
